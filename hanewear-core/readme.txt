Hanewear Core
=============

پلاگین سفارشی hanewear.com — بدون ویرایش تم parent Modista.

نصب
----
1. پوشه hanewear-core را در wp-content/plugins قرار دهید.
2. از پیشخوان WordPress پلاگین «Hanewear Core» را فعال کنید.
3. المنتور → ویجت‌های محصول (کارت، کاروسل، اسلاید): تنظیمات Order By / On Sale / Featured.

پس از آپدیت تم Modista
-----------------------
اگر ویجت‌های محصول parent عوض شدند، فایل‌های includes/Elementor/Widgets/ این پلاگین را با نسخه جدید parent همگام کنید (فقط در صورت نیاز).
